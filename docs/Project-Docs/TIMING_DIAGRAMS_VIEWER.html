Note over Client, Controller: 🔵 REQUEST TIMELINE (POST /api/v1/users/register) Client->>App: HTTP POST /api/v1/users/register (Multipart Form Data) App->>App: cors() checks origin header App->>App: asyncHandler wrapper Controller->>Controller: Validate required fields (username, email, password, avatar) Controller->>Model: User.findOne({ $or: [{ username }, { email }] }) Model->>Mongo: Query users collection Mongo-->>Model: User does not exist (null) Model-->>Controller: Proceed with registration Note over Controller, Cloudinary: ☁️ Cloudinary Upload & Cleanup Controller->>Cloudinary: JSON response App-->>Client: { statusCode: 201, data: {...}, message: "Success", success: true }
